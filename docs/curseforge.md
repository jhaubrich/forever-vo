# CurseForge listing text

Slug: `forever-vo`. Name: Forever Voiceover. Game version: 1.60.1 (Forever).
License: MIT. Category: Quests & Leveling. The voice pack is fan content, non-commercial.

---

**Forever Voiceover** reads quest offers, turn-ins and NPC dialogue aloud in
World of Warcraft: Forever, using voices generated by players from the game's
own NPC recordings. A talking-head frame in the client's style shows who is
speaking, with the text paged in time with the audio; lines queue when you
accept several quests at once; the quest log gets play buttons.

**Voice pack coming. This release collects the lines.** Quest and gossip text
is not in the game files, only the server has it, so a voice pack can only
cover lines someone has seen with the addon running. Until a pack is
installed you will hear nothing, and each unvoiced quest or NPC prints a
reminder in chat.

**How to help:** play with the addon on, especially Zephras Isle, the new
zones and any quest whose text changed from Classic. Then type `/fvo export`,
press Ctrl+C, and paste the string as a comment on the pinned issue at
https://github.com/quinn-dougherty/forever-vo/issues/1. Only the text, the
speaking NPC and the zone are shared; your character name is removed.

**Commands:** `/fvo` opens the options. `/fvo pause`, `resume`, `skip`,
`clear`, `replay`, `queue`, `head`, `reset`, `status`, `export`, `welcome`.

Source, tools and the pipeline that turns captured lines into audio:
https://github.com/quinn-dougherty/forever-vo
